# 얼마루 비전게임

**무료 로컬 카메라 움직임 앱.** 복잡한 보상이나 레벨 없이 음악을 고르고 한 곡 또는 한 세트를 진행합니다. 한 카메라로 1~2인이 함께할 수 있습니다.

## 실행

Windows에서 **`Start-Eolmaru.cmd`를 더블클릭**하세요. Node.js 22 이상과 Chrome/Edge가 필요합니다. 이 PC에는 Node.js가 설치되어 있습니다.

터미널에서 실행하려면:

```powershell
npm start
```

브라우저에서 **http://127.0.0.1:8765** 를 엽니다. 모델·WASM·음악·음성이 저장소에 포함되어 있어 내려받은 뒤에는 인터넷, API 키, F드라이브, 음악/음성 제작 엔진이 필요 없습니다. 카메라는 앱의 **카메라 켜기**를 눌렀을 때만 켜집니다. `index.html`을 직접 더블클릭하지 말고 시작 파일을 사용하세요.

## 0.8 처음부터 배우기·팔을 따르는 검·베이스 타격음

왼쪽 **◎ 처음부터 배우기**에서 별도 손 리듬 튜토리얼을 시작하세요. **자리 잡기 → 손 범위 → 양손 → 네 방향 → 박자 → 계속 베기 → 노래 선택**의 7단계입니다. 1~2인이 각자 연습하며, 짧은 음악이 반복되어 놓친 동작을 다시 시도할 수 있습니다. 탈락은 없습니다. 이전 단계·다시 연습·건너뛰기·나가기를 사용할 수 있고, 기존 선택곡과 편집 채보는 유지합니다.

카메라에서는 의자에 앉아 1인은 가운데, 2인은 왼쪽 P1·오른쪽 P2에 자리합니다. 어깨·골반·양손을 1초 동안 보여 준 다음 **내 손 범위 맞추기 · 5초**를 누르고 양손을 편하게 위·아래·좌·우로 움직이세요. 양손을 각각 움직여야 범위 확인을 통과합니다. 마우스 체험은 카메라 위치 확인과 구별해 표시합니다. **전신 스트레칭은 기존 별도 카테고리**입니다.

검은 팔꿈치에서 손목으로 향하는 방향과 손의 움직임에 따라 회전하고 잔상도 함께 돌아갑니다. **밝은 검 끝을 블록에 통과**시키세요. 팔꿈치가 보이지 않을 때는 손 이동 방향을 사용합니다. 마우스에서는 Q/E로 손, 1/2로 사람을 바꿉니다.

성공 타격음은 **1·2등급(굳·그레이트) / 3등급(퍼팩트) / 4·5등급(엑셀런트·야미)**의 세 베이스 소리입니다. 정확한 박자에 가까울수록 크게 울립니다. **설정 → 베이스 타격음**에서 음색별 미리듣기와 음량 조절을 할 수 있습니다. 기존 음악과 칭찬 음성은 유지합니다.

구현과 검증 근거: [튜토리얼 기획](docs/TUTORIAL_PLAN.md), [독립 검토](docs/TUTORIAL_REVIEW.md), [팔 방향 검](docs/SWING_DESIGN.md).

## 바탕화면·내 음악·춤추는 무대

- **바탕화면의 얼마루 비전**을 더블클릭해 실행합니다. 바로가기는 이 프로젝트 폴더의 실행기에 연결되어, 파일을 업데이트한 뒤 다시 실행하면 최신 게임을 엽니다. 새 PC에서는 아래 명령으로 바로가기를 만들 수 있습니다. 폴더를 이동했다면 기존 링크 위치를 수정하거나 새 위치에서 다시 설치하세요. 저장소를 자동 다운로드하는 업데이트 기능은 아닙니다.
- 블록을 맞히면 **쿵 울리는 베이스 타격음**이 납니다. **설정 → 베이스 타격음 → 타격음 들어보기**로 확인하고 소리만 따로 조절할 수 있습니다. 기존 저장 음량은 유지합니다.
- 왼쪽 **♫ 내 음악 파일 선택**으로 MP3/M4A/Ogg/WAV 등 브라우저가 지원하는 음악을 고릅니다. **2분 이상·100MB 이하**, 2~3분 곡은 전체, 긴 곡은 **앞 2분 30초**를 사용합니다. 원본 파일을 수정하거나 업로드하지 않습니다. 전신 모드에서 이 버튼을 누르면 손 리듬으로 전환하며, 선택 취소 시 손 리듬의 기존 곡을 유지합니다. BPM은 직접 입력합니다.
- 무지개색 무대 양끝의 창작 캐릭터 둘이 **두 장의 포즈 그림**으로 춤춥니다. 음악 두 박자마다 바뀌며 일시정지와 함께 멈춥니다. **설정 → 배경 캐릭터 춤 → 춤 멈추기**로 고정할 수 있고, 기기의 동작 줄이기 설정도 따릅니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/install-shortcut.ps1
```

## 0.5 손에 쥔 검과 다섯 가지 성공 반응

손이 인식되면 게임 화면에 **장갑 낀 손이 쥔 레이저검**이 나타납니다. 움직이면 검 전체의 잔상이 따라오며, 블록을 맞는 손과 방향으로 베면 네온 파편·충격파·작은 폭죽이 터집니다. 검 끝의 밝은 점이 판정 위치입니다.

성공한 베기의 박자 정확도를 20%씩 나눕니다: **굳 0~20% 미만 → 그레이트 20~40% 미만 → 퍼팩트 40~60% 미만 → 엑셀런트 60~80% 미만 → 야미 80~100%**. 등급은 사용자가 지정한 순서입니다. 정확도는 박자와 실제 교차 타격 시각의 차이로 계산하며, 탈락이나 보상은 없습니다.

안내31개는 밝은 한국 여성풍, 성공어5개는 명랑한 어린이 캐릭터풍으로 F 제작소의 설치된 Qwen 음성 모델에서 새로 합성했습니다. 모델은 제작할 때만 사용하고 게임은 작은 로컬 음성 파일을 재생합니다. 두 사람의 동시 성공은 각자 화면에 표시하며 목소리는 더 정확한 반응 하나를 고릅니다. 이미 칭찬 중이면 다음 칭찬을 쌓지 않습니다. 사이버 파편 타격음·안내·칭찬의 크기는 설정에서 각각 조절합니다.

감정·발음·음량 취향은 사람의 청취 확인이 남아 있습니다. [추가 기획](docs/FEEDBACK_PLAN.md) · [독립 검토](docs/FEEDBACK_REVIEW.md) · [음성 제작 기록](docs/VOICE.md).

## 화면과 플레이

메뉴·카메라·재생·설정·도움말은 왼쪽에 모았습니다. 오른쪽은 큰 게임 무대와 하단 카메라를 화면 높이에 맞춰 표시합니다. **플레이 시작을 누르면 실제 브라우저 전체화면**으로 전환합니다. Esc는 전체화면 해제와 일시정지, 계속하기는 재진입, 그만하기/완주는 창 화면으로 복귀합니다. 브라우저가 전체화면을 막으면 상태를 알리고 창 화면에서도 진행하며 왼쪽 버튼으로 재시도할 수 있습니다.

손 리듬은 **다가오는 블록을 양손으로 베는 한 곡**입니다. 빨강 **L은 내 왼손**, 파랑 **R은 내 오른손**입니다. 블록이 앞쪽 네모 영역에 도착할 때 표시된 화살표 방향으로 손을 움직입니다. 동그라미 블록은 어느 방향으로 베어도 됩니다. 손을 가만히 놓거나 한 번 누르는 것으로는 베기가 되지 않습니다. 1인 기본, 2인은 같은 채보를 각자 진행하며 탈락은 없습니다.

창작 네온 터널·광선검·블록·짧은 분할 효과는 Canvas로, 타격음은 로컬 Web Audio로 만듭니다. 참고 작품의 캐릭터·음원·로고·영상은 포함하지 않았습니다. Unity나 VR 장비 없이 현재 브라우저에서 실행합니다. [진행표](docs/SABER_PROGRESS.md) · [독립 검토](docs/SABER_REVIEW.md).

## 두 가지 카테고리

| 모드 | 구성 | 종료 |
|---|---|---|
| **전신 스트레칭** | **서서 하는 전신 운동이 기본**입니다. 목·어깨·가슴·몸통·허벅지·종아리·발목을 안내에 따라 움직입니다. 누운 세트와 커플 세트도 선택할 수 있습니다. 창작곡 3개의 앞 75초씩 사용합니다. | 3분 45초, 13개 동작 안내 후 종료 |
| **손동작 리듬** | **의자에 앉아 손만** 움직여 좌우 광선검으로 블록을 벱니다. 창작곡 또는 내 컴퓨터 음악을 선택합니다. 긴 곡은 앞 2분 30초를 사용합니다. | 선택한 한 곡 후 종료 |

상단에는 동작 예시/리듬, 하단에는 거울 방향 카메라가 나옵니다. 2인 모드는 화면 왼쪽 P1, 오른쪽 P2이며 서로의 구역을 바꾸면 자리 기준으로 다시 배정됩니다.

전신 세트는 동작을 실제로 따라 했을 때 하나의 움직임 루틴이 됩니다. **목과 하체는 시간·캐릭터·음성 안내**, 팔 벌리기와 옆구리는 카메라의 2D 유사도를 제공합니다. **누운 세트 전체는 시간·음성 안내만** 제공하며, **커플은 둘이 나란히 같은 서기 동작을 따라 하는 2인 세트**입니다. 서로 당기거나 밀지 않고 각자 안정된 지지물을 사용합니다. 카메라 점수로 전신 운동 수행, 운동 효과나 건강 상태를 확인하지 않습니다. 편안한 범위에서 움직이고 통증/어지럼이 있으면 멈추세요.

## 사용 방법

1. 카테고리와 인원 수를 선택합니다. 전신 세트의 서기/누워서/커플을 선택합니다. 서기는 벽이나 안정된 지지물 옆에서, 누운 세트는 매트에 먼저 누워 준비합니다.
2. 손동작 모드의 기본곡은 Maru Flow입니다. **내 음악 파일 선택**으로 2분 이상·100MB 이하의 MP3/M4A/Ogg/WAV 등을 고를 수 있습니다. 3분을 넘으면 앞 2분 30초를 사용합니다. 곡 BPM을 직접 입력하며 자동 비트 분석은 제공하지 않습니다.
3. 카메라를 켜고 권한을 허용합니다. 손 리듬은 어깨·골반·손, 전신 세트는 머리부터 발끝까지 몸 전체가 화면에 보이게 준비합니다.
4. 손 리듬은 **내 손 범위 맞추기 · 5초**로 편하게 닿는 범위를 맞출 수 있습니다. **플레이 시작**을 누르면 전체화면으로 전환하고 3초 뒤 시작합니다. 블록의 손 색과 화살표를 보고 손끝으로 통과하세요.
5. 곡/세트가 끝나면 종료 화면이 나옵니다. 기록은 원할 때 JSON으로 직접 저장할 수 있으며 누적 점수·랭킹·보상은 없습니다.

### 템포 적응 7곡과 계속 베기 — 0.6

손동작 리듬의 노래 목록에서 **템포 적응 · 80 → 140 BPM**을 고릅니다. 서로 다른 멜로디·음색의 창작 댄스/테크노 곡이며, 선택한 한 곡만 재생합니다.

| BPM | 곡 | 길이 |
|---|---|---|
| 80 | 앰버 스텝 | 2분 24초 |
| 90 | 벨벳 바운스 | 2분 29.3초 |
| 100 | 유리빛 아케이드 | 2분 33.6초 |
| 110 | 메트로 스파크 | 2분 28.4초 |
| 120 | 프리즘 모션 | 2분 32초 |
| 130 | 오로라 서킷 | 2분 27.7초 |
| 140 | 혜성 스프린트 | 2분 30.9초 |

시작 전에 왼쪽 **타겟 접근 속도**를 0.6~1.6배로 조절할 수 있습니다. **등장 간격**은 기본 최소2박 또는 여유로운 최소4박입니다. 여유롭게는 타겟 묶음을 하나씩 건너뛰며 양손 동시 묶음은 함께 유지합니다. 음악의 BPM·음정·판정 시각은 바꾸지 않습니다. 설정은 이 브라우저에 저장되고 곡 진행 중에는 잠깁니다. 가져오거나 만든 채보에도 실행용 설정만 적용하며 편집·저장하는 원본은 보존합니다.

**네모는 한 번 베기, ∞는 계속 베기**입니다. 지속 타겟은 같은 손으로 표시 영역 안을 좌우·위아래로 계속 움직입니다. 정지한 손은 진행되지 않습니다. 새 곡에는 양손을 번갈아 사용하는 2~4박 지속 타겟이 들어 있습니다. 전체 시간의60% 이상 움직이고 마지막25% 구간에도 움직여야 완성됩니다. 초록 막대가 차도 끝부분까지 움직이세요. 충족하면 끝나는 박자에 효과·칭찬이 한 번 나오며, 늦은 카메라 입력에는 최대0.45초 여유를 둡니다. 칭찬 등급은 처음 닿은 박자 정확도이고 지속 이동률은 별도입니다. 실패해도 한 곡은 계속됩니다.

[개발 TODO·수락 기준](docs/TRAINING_PLAN.md) · [독립 검토](docs/TRAINING_REVIEW.md) · [7곡 제작·측정 기록](docs/TEMPO_MUSIC.md).

카메라 없이 **마우스·키보드로 연습**할 수 있습니다. `1/2`로 사람, `Q/E`로 왼손/오른손을 고르고 **마우스 이동 또는 WASD/방향키 연속 이동**으로 벱니다. 시험 입력은 한 손씩 조작하며, 카메라는 최대 네 손을 동시에 처리합니다. 전신 모드의 **카메라 없이 안내 보기**는 음악/음성/캐릭터 안내만 제공하며 자세 유사도를 만들지 않습니다.

설정에서 음악/코치/타격음 볼륨, 손 이동 범위, 입력 지연 보정(±250ms), 효과 품질, 인식 빈도를 바꿀 수 있습니다. 지연이 느껴지면 보정을 +방향으로 조절합니다. 영상은 저장·전송하지 않고 마이크 권한도 요청하지 않습니다. 설정만 브라우저에 저장합니다. 탭을 숨기면 진행을 멈춥니다.

### 빠른 테크노·댄스 추가곡 — 0.4.1

왼쪽 **이번에 들을 노래**에서 선택합니다. 새 곡을 고르면 곡의 BPM과 채보가 함께 적용됩니다.

| 곡 | 장르 / 빠르기 | 길이 |

| **Neon Drive · 네온 질주** | 테크노 · **150 BPM** | 2분 33.6초 |
| **Pulse Rush · 빛의 댄스** | 댄스 · **156 BPM** | 2분 27.7초 |

두 곡은 강한 4박 킥, 빠른 하이햇, 빌드업과 드롭을 넣은 창작 무가사 음악입니다. 곡이 빨라도 블록은 최소 2박 간격으로 배치하며 탈락은 없습니다. 기존 Maru Flow와 내 컴퓨터의 노래 선택도 유지합니다. 전신 스트레칭은 기존의 편안한 3곡·225초 세트를 사용합니다.

## 채보 만들기

손 리듬의 왼쪽 **채보 만들기**에서 음악을 들으며 블록을 기록하고 위치·손·방향·시각을 수정합니다. 삭제, 실행 취소, 구간 반복 미리보기, JSON 저장/불러오기를 제공합니다. **게임에 적용**을 누르면 이번 노래에 적용됩니다. 로컬 곡은 규칙적인 간단 패턴으로 시작하며 자동 음악 분석은 없습니다.

타겟 종류에서 **한 번 베기 / 계속 베기**를 선택합니다. 계속 베기는0.5~6초·자유 방향이고, 종료0.5초 후에 같은 손·칸의 다음 타겟을 놓을 수 있습니다. `kind:'sustain'`과`durationSeconds`를 사용하는 v1 JSON이며 기존 단타 JSON도 그대로 지원합니다.

기본 채보는 `public/charts/maru-flow.saber.json`입니다. 최소 2박 간격, 한 시각 최대 좌우 한 개씩, 4×3 위치, 곡 시작·끝 여유를 검사합니다. 잘못된 파일은 현재 채보를 바꾸지 않습니다. JSON에는 음악 파일 자체가 포함되지 않으므로 같은 노래를 함께 선택해야 합니다.

## 검증과 한계

개발 PC는 Windows 11 / i5-12400F / GTX 1660 Ti / 메모리 약 32GB입니다. MediaPipe Lite, 640px 추론 입력, 기본 최대 12회/초 인식, 제한된 Canvas 해상도를 사용합니다. GPU 초기화가 안 되면 CPU로 다시 시도합니다.

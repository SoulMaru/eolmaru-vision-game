# 얼마루 비전게임

**무료 로컬 카메라 움직임 앱.** 복잡한 보상이나 레벨 없이 음악을 고르고 한 곡 또는 한 세트를 진행합니다. 한 카메라로 1~2인이 함께할 수 있습니다.

## 실행

Windows에서 **`Start-Eolmaru.cmd`를 더블클릭**하세요. Node.js 22 이상과 Chrome/Edge가 필요합니다. 이 PC에는 Node.js가 설치되어 있습니다.

터미널에서 실행하려면:

```powershell
npm start
```

브라우저에서 **http://127.0.0.1:8765** 를 엽니다. 모델·WASM·음악·음성이 저장소에 포함되어 있어 내려받은 뒤에는 인터넷, API 키, F드라이브, 음악/음성 제작 엔진이 필요 없습니다. 카메라는 앱의 **카메라 켜기**를 눌렀을 때만 켜집니다. `index.html`을 직접 더블클릭하지 말고 시작 파일을 사용하세요.

## 두 가지 카테고리

| 모드 | 구성 | 종료 |
|---|---|---|
| **전신 스트레칭** | 안정된 의자에 앉아 목·어깨·가슴·몸통·허벅지·종아리·발목을 안내에 따라 움직입니다. 창작곡 3개의 앞 75초씩 사용합니다. | 3분 45초, 14개 동작 안내 후 종료 |
| **손동작 리듬** | 위·아래·좌·우 방향으로 손을 뻗습니다. 창작곡 또는 내 컴퓨터의 2~3분 음악을 선택합니다. | 선택한 한 곡 후 종료 |

상단에는 동작 예시/리듬, 하단에는 거울 방향 카메라가 나옵니다. 2인 모드는 화면 왼쪽 P1, 오른쪽 P2이며 서로의 구역을 바꾸면 자리 기준으로 다시 배정됩니다.

전신 세트는 동작을 실제로 따라 했을 때 하나의 움직임 루틴이 됩니다. **목과 하체는 시간·캐릭터·음성 안내**, 팔 벌리기와 옆구리는 카메라의 2D 유사도를 제공합니다. 카메라 점수로 전신 운동 수행, 운동 효과나 건강 상태를 확인하지 않습니다. 편안한 범위에서 움직이고 통증/어지럼이 있으면 멈추세요.

## 사용 방법

1. 카테고리와 인원 수를 선택합니다. 전신 세트는 안정된 의자를 준비합니다.
2. 손동작 모드의 기본곡은 Maru Flow입니다. **내 컴퓨터의 노래…**로 120~180초의 MP3/Ogg/WAV 등을 고를 수 있습니다. 곡 BPM을 직접 입력하며 자동 비트 분석은 제공하지 않습니다.
3. 카메라를 켜고 권한을 허용합니다. 손 리듬은 어깨·골반·손, 전신 세트는 의자와 발끝이 화면에 보이게 준비합니다.
4. **플레이 시작**을 누릅니다. 방향 입력은 손을 가슴 앞으로 모았다가 한 방향으로 뻗고 다시 돌아오는 방식입니다.
5. 곡/세트가 끝나면 종료 화면이 나옵니다. 기록은 원할 때 JSON으로 직접 저장할 수 있으며 누적 점수·랭킹·보상은 없습니다.

카메라가 없어도 **키보드로 체험**을 선택할 수 있습니다. 손 리듬 P1은 `A W S D`, P2는 방향키입니다. 전신 모드에서는 카메라 없이 음악/음성/캐릭터 안내만 따라갈 수 있습니다. 자세 유사도를 만들어 내지 않습니다.

설정에서 한국어 코치 켜기/끄기, 음악/코치 볼륨, 손 감도, 동작 지연 보정, 인식 빈도를 바꿀 수 있습니다. 영상과 음성 입력은 저장·전송하지 않고 마이크 권한도 요청하지 않습니다. 설정만 브라우저에 저장합니다. 탭을 숨기면 진행을 멈춥니다.

## 창작 자산과 로컬 제작

- **마루**: 민트색 로봇 코치와 새 배경 그림. 생성 프롬프트와 그림 기록: [ART](docs/ART.md).
- **음악 3곡**: Maru Flow, Maru Breeze, Maru Sunset. 각 150초·112 BPM. F 얼마루 제작소의 경량 합성 기능과 새 편곡 사용. [음악 기록](docs/MUSIC.md).
- **한국어 안내 19개**: F 목소리 제작소의 설치된 해미 음성을 사용해 완전 로컬 생성. [음성 기록](docs/VOICE.md).
- 코드 MIT, 외부 코드/모델/음원 출처는 [라이선스 안내](THIRD_PARTY_NOTICES.md).

## 검증과 한계

개발 PC는 Windows 11 / i5-12400F / GTX 1660 Ti / 메모리 약 32GB입니다. MediaPipe Lite, 640px 추론 입력, 기본 최대 12회/초 인식, 제한된 Canvas 해상도를 사용합니다. GPU 초기화가 안 되면 CPU로 다시 시도합니다.

자동 판정 검사, 브라우저의 손 리듬·225초 세트 전환, 로컬 모델 초기화, 음원/음성 파일 해시를 확인했습니다. **실제 두 사람이 움직이는 카메라 정확도, 실제 체감 지연, 사람 청취는 아직 검증 대기**입니다. 합성 카메라 결과를 실사용 성능으로 표시하지 않습니다. 최신 상세 결과는 [TEST_RESULTS](docs/TEST_RESULTS.md)와 [독립 검토](docs/REVIEW.md)에 기록합니다.

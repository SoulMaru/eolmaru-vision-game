# 개발 이력 — 2026-09-27 KST

## 0. 실제 작업 공간과 요구 확인

Adkiller 폴더가 Git 저장소가 아니고 기존 앱들이 있음을 확인했다. 이를 수정하지 않고 비어 있던 `8.visiongame` 아래 독립 프로젝트를 만들었다. CPU/GPU/메모리, USB 카메라 등록, GitHub 연결, F 제작소의 음악/음성 소스를 확인했다. GitHub CLI에 캐시된 계정 이름과 현재 API 사용자명이 달라 현재 로그인 `SoulMaru`를 다시 확인하고 그 계정에 저장소를 생성했다.

## 1. 조사·설계

JustMove와 Neon Dash를 내려받고 MIT 파일/커밋을 기록했다. Reddit HandSaber와 NHS 운동 안내를 조사했다. 생성엔진은 구현, 검토엔진은 독립 판정/소스 확인, 기획엔진은 음악/음성/출처/범위를 담당했다. 영상 외부전송·유료런타임·상용곡 복제 없이 브라우저 로컬 방식으로 결정했다.

## 2. 첫 MVP와 교차 검토

1~2인 입력, 4방향 중립 복귀, 타이밍 판정, 상단예시/하단영상, 무탈락을 구현했다. 로컬 MediaPipeJS/WASM/Lite모델을 동봉했다. 창작 마루 캐릭터·배경 및 150초 곡을 만들었다. 독립검토 R01~R06을 수정하고 회귀검사를 실행했다.

## 3. 사용자 추가 지시 반영

- F 목소리 기능을 활용해 9개 기본 코치 음성을 생성하고 로컬 재생/볼륨/음악음량 감소를 연결했다.
- Unity Hub/Krita 조건부 사용 허용을 기록했다. 현재 가벼운2D에 이득이 입증되지 않아 새 엔진을 도입하지 않았다.
- 복잡한 게임이 필요 없다는 지시에 보상·레벨·콤보·누적점수 화면을 제거하고 곡선택/진행/종료 흐름으로 줄였다.
- 전신 세트와 손동작 전용 분리 지시에 기본 의자형14동작, 3곡의앞75초씩225초 세트로 확장했다. 추가2곡과 전신10개음성을 제작해 총3곡/19음성으로 구성했다.
- 목/하체는 정면2D정밀판정을 할 수 없어 시간안내로 명확히 분리했다. 팔/몸통만 유사도 표시한다. 예전150초 상체전용 일정 코드는 제거했다.

## 4. 정리·재현성

곡/음성 생성 중간파일은 최종 배포에서 제외했다. 라이선스와 선택한 소스커밋·모델/음원/음성해시를 기록했다. 런타임중복·누락·외부URL검사와 브라우저 곡전환/종료/키보드/파일선택을 실행했다. 자동시험과 합성카메라 결과를 실제1~2인 운동검증과 구분했다. 최신 실행결과는 TEST_RESULTS와 ASSET_AUDIT에서 확인한다.

## 5. 사용자 자세 선택 및 두 모드 정정 — 0.2

사용자의 서기 기본/누워서/커플 요청과 손 리듬은 앉아서 손만이라는 정정을 반영했다. 초기 의자 스트레칭을 폐기하고 13단계225초 프로필 세 개로 교체했다. 커플은 나란히 서서 독립 동작, 2인 자동 선택/잠금이다. 누운 세트는 전 구간 시간·음성 안내이며 카메라 정확도를 만들지 않는다. 서기/누운 새음성19개 생성, 미사용 기존7개 제거로 최종31개. 프로필 선택기, 전용 캐릭터 자세, 안내와 결과를 통합하고 브라우저 프로필8개 검사를 추가했다. 새 렌더러의 오른쪽 다리 표시와 무채점 표시 문제를 독립 검토 후 수정했다.

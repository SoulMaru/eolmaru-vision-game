## 소스 연결 검토

- 시작 클릭에서 `audio.play()`, AudioContext 준비, Fullscreen 요청을 await 이전에 호출한다. 전체화면 여부는 CSS 확대와 별도로 `document.fullscreenElement`와 `fullscreenchange`를 사용한다. ESC 이탈은 `pauseGame()`으로 전달하고 세션 중간 상태와 예약 효과음을 정리한다.
- FullscreenController는 요청 세대와 최신 의도를 구분한다. 이전 요청이 늦게 끝나도 새 요청의 전체화면을 임의로 닫지 않는다. 앱의 종료와 사용자 ESC는 구분한다.
- 판정, 큐, 장면 전환은 음악의 `currentTime`에서 보정값을 뺀 시각을 공유한다. 짧은 입력 잔광에는 성능 시계를 사용한다. 프레임 누적 카운터를 곡 시계로 쓰지 않는다.
- 시범8박과 응답8박을 구분하며 모든 응답 간격은 최소2박이다. 사용자곡은 입력한 BPM으로 정형 채보를 만들고, 자동 음원 분석을 제공한다고 표시하지 않는다.
- Canvas에 각 플레이어의 장면 구획을 설정하고 판정 상태를 별도로 참조한다. 카메라는 원본 영상 비율로 contain 영역을 계산하고 영상과 관절에 동일한 레터박스·거울 변환을 적용한다.
- 데스크톱 메뉴는224px, 주 영역은 상단 무대7/하단 카메라3 비율이며 좁은 화면에 별도 규칙이 있다. 설정/도움말을 열면 진행을 멈춘다. 실제 긴 한국어 글자·작은 창 가독성은 생성엔진 화면 검증이 필요하다.
- Canvas 장식 반복은 고정 개수이며 입자 배열을 프레임마다 누적하지 않는다. 효과음 oscillator는 ended에서 연결을 해제하고 정지 시 남은 예약도 중지한다. 저동작 설정에서 배경 이동과 캐릭터 점프를 줄인다.
- 기존 손 리듬/전신 분리, 서기 기본·누워서·커플13단계225초, 바닥 무채점, 단곡 종료, 무탈락 조건은 기존 회귀와 연결 소스에서 유지한다. 원본 참고영상·추출 프레임은 런타임으로 불러오지 않는다.

## 브라우저에서 추가로 확인할 순서

1. Chrome/Edge에서 시작을 직접 눌러 실제 전체화면 진입을 확인한다. `fullscreenElement`뿐 아니라 탭·주소창·작업표시줄이 숨겨진 창도 확인한다.
2. 카운트다운 중 ESC, 재생 중 ESC, 재개 후 ESC, 그만하기, 곡 종료, 다시 시작을 순서대로 실행한다. 의도치 않은 재진입과 숨은 음악 재생이 없어야 한다.
3. 전체화면 거절·미지원 상태에서도 창에서 시작 가능하고, 조작 버튼과 거절 안내가 남아 있어야 한다. 카운트다운 전 재생 거절과 늦게 완료되는 전체화면 요청도 정리되어야 한다.
4. 1인/2인 리듬쇼를 각 막에서 확인한다. 시범과 응답 신호, 잘못된 방향/박자, 같은 손을 계속 유지한 경우를 비교한다. 유효 입력 없이 성공 장면이나 소리가 반복되면 안 된다.
5. 설정·도움말, 탭 숨김, 큰 시각 이동, 곡 끝에서 예약음이 남거나 지난 예고가 한꺼번에 재생되지 않는지 확인한다. 실제 음량 균형은 사람 청취로 별도 기록한다.
6. 1920×1080,1280×720,390px 폭에서 메뉴·시작/정지·2인 표시와 카메라 좌우를 확인한다. 화면 크기 변화 후 캐릭터/관절이 찌그러지거나 구획이 바뀌면 안 된다.
7. 새 브라우저 세션에서도 로컬 자산만 요청하는지 확인한다. 실제 사람의1인/2인 추적·체감 지연은 합성 영상 시험과 구분한다.

## 공식 근거와 후속 검색어

최종 판단: 새14개와 기존27개 독립 검사를 모두 통과했고 S14~S16 수정 코드를 확인했다. 전달을 막는 미해결 소스 결함은 발견하지 않았다. 실제 사람의 카메라 정확도·체감 동기·스피커 청취와 작은 화면의 최종 가독성은 자동 검사 결과만으로 완료 처리하지 않는다.

[WHATWG Fullscreen 표준](https://fullscreen.spec.whatwg.org/)의 사용자 활성화 요구, 활성화 소비, Promise, fullscreenchange 및 fullscreenElement를 확인했다. `navigationUI: hide`는 브라우저에 요청하는 선호이며 브라우저의 사용자 설정을 무시하는 보장이 아니다. 사용자 요청에 따른 실제 창 확인은 여전히 필요하다.

후속 검색어: `requestFullscreen transient activation pending exit race`, `fullscreenchange silent programmatic exit`, `Web Audio scheduled oscillator stop backward seek`, `HTMLMediaElement currentTime call response cue cursor`, `Canvas per-player clipping camera letterbox`.

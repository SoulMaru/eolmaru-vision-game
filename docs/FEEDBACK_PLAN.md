## 정확도와 성공어 계약

성공 판정(`kind === 'hit'`)의 실제 교차 타격 시각을 `t`, 해당 노트의 `hitTime`을 `h`라 할 때 `정확도 = 100 × (1 − |t − h| / 0.25)`다. `t`는 기존 연속 선분/블록 교차에서 결정한 음악 시각이며 렌더 시각·이벤트 도착 시각으로 대체하지 않는다. 기존 채보 오프셋과 입력 보정을 중복 적용하지 않는다. 부동소수점 경계 오차만0~100에 제한하고, **등급은 표시용 반올림 전 값**으로 나눈다.

| 정확도 구간 | 화면·성공어 |
|---|---|
| 0 이상20 미만 | 굳 |
| 20 이상40 미만 | 그레이트 |
| 40 이상60 미만 | 퍼팩트 |
| 60 이상80 미만 | 엑셀런트 |
| 80 이상100 이하 | 야미 |

이는 사용자가 지정한 순서이며 통상적인 게임 등급 순서로 바꾸지 않는다. 중앙 타격은100, ±0.05초는80, ±0.10초는60, ±0.15초는40, ±0.20초는20, 허용창 끝 ±0.25초는0이다. 경계의 양옆과 양쪽 시간 방향을 검사한다. 유효하지 않은 수치, `wrongCut/miss/untracked/skipped`, 정지 중 입력에는 성공어·성공 폭죽·성공 타격음을 만들지 않는다. 노트당 플레이어별 한 번만 반응한다. 수치는 게임 타이밍이며 운동 정확도나 의료적 평가가 아니다.

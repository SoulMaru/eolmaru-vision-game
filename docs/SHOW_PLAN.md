## 최신 요청과 유지할 범위

사용자는 로컬의 『리듬 천국 미라클 스타즈』 소개영상을 참고해 메뉴와 기타 기능을 왼쪽에 모으고, 게임 시작 시 실제 전체 화면으로 전환하여 장면을 크게 보여 달라고 요청했다. 핵심 경험은 **소리 예고 → 박자에 맞는 동작 → 장면의 즉각적인 반응**이다.

두 카테고리는 그대로 분리한다.

| 카테고리 | 이번 연출 | 유지 조건 |
|---|---|---|
| 손동작 리듬 | 의자에서 손만 움직이며 소리 예고를 듣고 네 방향으로 반응. 한 곡 안에 창작 3막이 자동 전환 | 120~180초 선택곡 한 곡 후 종료, 최소 2박 동작 간격, 카메라 또는 키보드 체험, 1~2인 |
| 전신 스트레칭 | 큰 마루 예시, 휴식 호흡 연출, 현재/다음 부위와 세트 순서 표시 | 기본 서기·누워서·커플, 각각 13단계225초, 창작곡3개×75초, 누운 동작 전부 무채점 |

3막은 같은 곡/세트 안의 배경과 행동 표현이다. 별도 게임 수를 늘리거나 레벨·해금·보상·경쟁 점수를 추가하지 않는다. 기존 무탈락, 좌우 2인 구역, 무료 로컬 실행, 영상 저장·전송 없음 조건도 유지한다. 영상에 등장하는 게임 수나 부가 모드를 본 앱의 구현 약속으로 가져오지 않는다.

## 창작 3막

세 장면은 기본곡에서는 같은 박자 시계를 공유한다. 사용자곡도 직접 입력한 BPM으로 단순 패턴을 만들며, 음원 내용을 이해하거나 자동 비트를 추출했다고 표시하지 않는다. 손 리듬의 반응 목표 사이에는 최소2박을 두어 손을 되돌리고 다음 예고를 들을 여유를 확보한다.

| 막 | 장면과 동작 의미 | 소리 예고와 리듬 제안 | 반응 표현 |
|---|---|---|---|
| 별빛택배 | 마루가 작은 별 소포를 위·아래·좌·우의 우편구름으로 보냄 | 짧은 두 음 예고 후 목표 박자. 2박/4박 간격과 방향 교대로 기본 리듬을 익힘 | 맞춘 방향으로 소포가 날아가고 별 궤적·도착 파동. 놓치면 구름이 부드럽게 흘러가며 다음 예고 유지 |
| 구름북 | 마루의 손짓에 네 방향 구름이 부드러운 북처럼 울림 | 먼저 들려준 짧은 묶음을 듣고 응답. 연속 두 동작과 한 번 쉬는 구성을 섞되 모든 동작 간격은 최소2박 | 맞춘 구름이 눌렸다 펴지고 둥근 파문. 2인 색을 분리해 각자의 반응 위치를 보여 줌 |
| 정원마법 | 마루가 씨앗에 빛과 물방울을 보내 정원을 꾸밈 | 앞에서 익힌 간격을 섞고 예고 뒤 긴 쉼을 포함. 쉼 동안 동작을 재촉하지 않음 | 해당 방향에 잎·꽃·빛고리가 피고 곡 끝에 정원이 편안히 머무름 |

패턴 다양성은 노트를 촘촘하게 만드는 것으로 해결하지 않는다. 방향 순서, 예고의 묶음, 2박/4박 등의 빈 간격과 장면 반응으로 변화를 만든다. 세 장면의 표현은 비슷한 색상의 단순 배경 변경에 그치지 않고 소포 이동·구름 파동·꽃 피기라는 다른 사건으로 구별한다.

전신 모드에서는 같은 테마를 쓰더라도 박자에 맞춰 빠르게 방향을 찍도록 요구하지 않는다. 마루가 기존 동작을 크게 시범 보이고, 휴식 구간에는 느린 호흡·작은 환경 움직임을 쓴다. 목·하체·바닥의 안내 전용 상태와 기존 동작 시간이 연출 때문에 바뀌지 않아야 한다. 커플은 나란히 각자의 범위에서 움직이며 서로 잡아당기는 장면을 추가하지 않는다.

## 성능·정리 관문

1. 기존 MediaPipe Lite와 제한된 추론 빈도를 유지한다. 새 대형 엔진이나 이미지 모델을 게임 런타임에 추가하지 않는다.
2. 장면의 입자 수·잔상 수·그리기 해상도를 제한한다. 프레임마다 오디오 노드나 무제한 오브젝트를 누적하지 않는다.
3. 1인/2인·무대/카메라 비율·전체 화면 크기에서 CPU/GPU 작업이 늘어난 부분을 관찰한다. 합성 입력의 관측치를 실제 두 사람의 성능으로 쓰지 않는다.
4. 사용하지 않는 이전 레이아웃·연출 코드와 중복 자산을 확인하고, 변경에 직접 필요한 회귀를 통과한 뒤 정리한다.
5. 파일 크기·해시·오프라인 요청 검사를 갱신한다. 화려해졌다는 주장은 실제 화면 확인으로, 동기가 좋아졌다는 주장은 실제 청취/움직임 시험으로 나누어 기록한다.

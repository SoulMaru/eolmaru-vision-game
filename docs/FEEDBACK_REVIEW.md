# 성공 판정·사이버 음향·코치 음성 독립 검토

검토엔진,2026-09-27 KST. 시작 기준 `67551be`에서 변경 없는 상태를 직접 확인했다. 현행 AGENTS/README/PLAN/REVIEW/HANDOFF와 core/game/show/app 및 기존 회귀를 읽었다. 이 문서와 `tests/review-feedback.test.mjs`,기존 음악 검사의 음성 불변조건만 검토엔진 소유다. 게임 소스·작곡기·음성 제작 코드·커밋은 수정하지 않는다.

## 의도된 보존 조건 변경

사용자는 코치31개 음성 전체 교체와 성공어5개 추가를 요청했다. 따라서 과거 음악 확장에서 사용한 **음성 manifest 바이트 고정 조건만 제거**했다. 이 변경은 오래된 음성을 남기도록 강제하던 검사의 목적을 새 요청에 맞추는 것이며,기존3곡 Ogg/메타6개 고정 해시는 그대로다. 교체된 코치의 cue 참조·실제 파일/해시·무료 로컬 재생은 기존 profile 검사와 새 feedback 검사로 확인한다. 이전 MUSIC_REVIEW의 당시 보존 검증 이력은 수정하지 않는다.

## 발견 및 수정 이력

**RF01 — 일부 음성이 먼저 도착한 상태에서 첫 시작 시 나머지 등급이 무음.** 초기 `load()`에서 good1개만 완료한 뒤 `prepare()`를 부르면 `encoded.size`가0이 아니므로 진행 중 preload를 기다리지 않고 그1개만 디코드했다. 뒤이어4개 파일이 정상 도착해도 해당 곡에서는 다시 준비하지 않아 칭찬이 빠졌다. `tests/review-feedback.test.mjs`의 `initial preload` 회귀로 실제 `false !== true`를 확인했다. 기본20개는20/20 통과(160.0037ms),추가 RF01 단독 실행은1개 실패(110.482ms)였다. 이력은 원인 발견의 기록이며 수정 후 결과는 아래에 별도 기록한다. 게임 소스는 생성엔진이 수정한다.

생성엔진이 `load()`의 진행 중 Promise를 공유하고,`prepare()`가 그 완료를 기다린 뒤5개 미만이면 재시도하도록 수정했다. 검토엔진이 수정 소스를 읽고 새 feedback 전체를 직접 재실행하여 **21/21 통과,0 실패·스킵,167.413ms**를 확인했다. RF01은 이 경합 재현 조건에서 해결됐다. 로딩 후 실제 소리 발음·감정이 승인됐다는 뜻은 아니다.

**RF02 — 최대 동시 사이버 효과의 합산 peak 초과.** 생성엔진이 실제 브라우저 `OfflineAudioContext`에서 production 합성기를5등급×1/8동시,48kHz·stereo·1초·효과음량100%로 렌더해8동시 peak1.45~1.69를 발견했다. 공유 gain에 `1/sqrt(현재 버스트 수)` 감쇠를 적용한 후 같은10조건의 최댓값은0.59856으로 보고됐다. 이10회는 **생성엔진 실행 결과**다. 검토엔진은 production 소스와 검사 코드를 읽고 별도 RF02 회귀를 추가해1→2버스트 감쇠·종료 후 복원·stop 후 이전 ended가 새 master를 끊지 않는지 확인했다. 추가 후 feedback **22/22 직접 통과,0 실패·스킵,151.2853ms**다. 이 측정은 타격음 단독이며 음악과 음성까지 합한 최종 출력의 모든 조건이나 실제 청취를 증명하지 않는다.

## 전달받은 브라우저 근거

생성엔진은 `tests/browser-feedback.js`32개와 기존 흐름15개 통과를 보고했다. 실제 앱의2인 포인터 베기에서 각각25.887% 그레이트와76.919% 엑셀런트 event가 전달됐고,실제5버퍼 로드·재생과 pause/seek/mute/stop 정리를 검사했다. 등급5개 모두에 대한 추가 재생은 진단용 합성 hit이며 실제 카메라 성공으로 해석하지 않는다. 검토엔진이 이 브라우저 실행을 별도로 재수행한 것은 아니다.

## 검증 한계

검토엔진은 이번 변경에서 실제 사람의 카메라 움직임·스피커 청취·감정/발음·사이버 음색 만족도를 시험하지 않았다. WebAudio 모형 검사는 노드/타이머/중복 재생 결정을 확인하며 실제 브라우저 오디오 출력과 음량 균형을 대신하지 않는다. 생성엔진의 브라우저 결과는 전달받은 결과임을 밝히고 별도로 연결한다. VoiceDesign이 파일마다 완전히 같은 화자 정체성을 유지한다고 보증하지 않는다.

최종 독립 기술 검토 범위에서는 RF01/RF02 해결과 자동 회귀·음성 자산·음악 보존을 확인했고 추가 차단 결함은 발견하지 않았다. 밝은 여성풍/어린이풍·한국어 발음·감정·실제 스피커 믹스 만족도와 사람1/2인 카메라 실사용은 수동 확인 항목으로 남긴다.

# 0.8 별도 튜토리얼·팔 방향 검·세 가지 베이스 기획

2026-09-27 KST. 시작 기준 `241c02a`이며 기획엔진은 AGENTS, README/PLAN/REVIEW/HANDOFF, 최종 튜토리얼·앱·보정·검/효과음 소스와 SWING_DESIGN/TUTORIAL_REVIEW, 저장된 최종 검사 보고·자산 감사를 대조했다. **TU01~09 개발 수락 완료, TU10 실제 사람 사용은 대기**다. 독립 순수 검사·합성 시각·실제 PCM과 생성엔진의 브라우저 실습을 구분한다. 기획엔진의 수정 범위는 이 문서뿐이며, 이전 0.7의 자동 148개·브라우저 89개를 이번 검사 결과로 쓰지 않는다.

## 확정 요구와 보존

- 왼쪽에 **별도 튜토리얼 카테고리**를 제공한다. 처음 자리 잡기부터 범위 맞추기, 양손·방향·타이밍·계속 베기, 한 곡 고르기까지 직접 연습한다. 실패는 재시도 기회이며 탈락·HP·새 보상·레벨 해금은 없다.
- 최대 2인이 각자 연습한다. 한 사람의 성공으로 다른 사람까지 성공 처리하지 않는다. 다음 단계는 각자의 완료 또는 **명시적 건너뛰기**를 구분하고, 돌아가기·다시 연습·나가기 경로를 제공한다.
- 손목을 따르는 기존 검에 **팔꿈치→손목 방향**을 반영한다. 검 끝의 밝은 점이 기존 손목 판정 위치라는 계약은 그대로다. 긴 검 그림, 팔 방향, 잔상이 판정 범위를 늘리거나 베기 방향을 대신 결정하지 않는다.
- 베이스 타격음은 기존 성공 등급 **1·2 / 3 / 4·5의 세 종류**다. 기존 순서인 굳·그레이트·퍼팩트·엑셀런트·야미와 정확도 경계를 바꾸지 않는다. 정확할수록 효과음 크기를 높이되 저장 음량·음소거·동시 감쇠·출력 제한을 유지한다.
- 일반 손 리듬의 곡 선택→한 곡 종료, 원본/실행용 채보 분리, 로컬 음악 길이 정책, 1~2인, 실제 전체화면·Esc 정지, 별도 서기/누워서/커플 **225초 전신 세트**를 보존한다. 기존 **12곡·36개 음성**은 변경하지 않는다. 바탕화면 실행기, 창작 두 포즈 춤과 정지/동작 줄이기 옵션, 무료 로컬 실행도 유지한다.

실제 실습은 **Maru Flow 112 BPM의 앞 32박, 약 17.14초**를 반복한다. 양손은 각 1회, 방향은 네 방향 각각 1회, 타이밍은 정확도 60% 이상 2회, 계속 베기는 1회 성공하면 된다. 손·방향·타이밍 채보는 4/8/12/16/20/24박, 지속 채보는 8/20박에 4박 길이로 등장한다. 접근 0.8배/간격 2박을 학습에만 고정해 일반 설정을 바꾸지 않는다. 기존 150초 채보 검증을 그대로 통과하는 내부 채보를 사용하고 오디오의 앞 구간만 반복하므로 일반 곡/편집기/파일의 길이 검증을 완화하지 않는다. 음악 재생 속도는 바꾸지 않는다.

카메라 자리 확인은 올바른 구역에서 어깨·골반·양손이 **연속 1초** 관측되어야 한다. 5초 범위 보정은 사람별 양손 각각의 유효 표본과 가로/세로 이동을 확인한다. 서로 떨어진 정지 양손이나 한 손만 움직인 표본으로 성공하지 않는다. 공용 '미완료 단계 건너뛰기'를 누르면 현재 미완료인 사람만 `skipped`, 이미 완료한 사람은 해당 완료 상태로 기록한다. 포인터의 자리/범위 통과는 `test`로 구분한다.

## 구현 연결과 주의점

**독립된 학습 상태.** `src/tutorial-core.mjs`가 단계별 개인 결과를 관리하고 `src/tutorial.mjs`가 별도 Audio와 SaberGame을 사용한다. 일반 `track`, `localSongUrl`, 원본 채보와 `lastResult`를 연습 데이터로 교체하지 않는다. 연습을 마쳐 '한 곡 고르러 가기'를 누를 때만 카메라 보정값을 일반 손 리듬에 전달한다. 중간 나가기는 전달하지 않는다. 오디오를 처음 허용한 뒤 전체화면 준비 중에는 일시정지하고, 준비 완료 후 같은 시점에서 시작한다. generation 번호로 나가기 뒤 늦은 재생과 중복 반복을 차단하고 나갈 때 학습 Audio의 src를 해제한다.

**카메라와 체험의 구분.** 실제 카메라 권한은 사용자의 켜기 동작을 따른다. 포인터는 화면 조작 연습이며 몸 위치·팔 추적·2인 카메라 성능의 증거가 아니다. 기존 `beginCalibration`/`finishCalibration`을 연결할 때 사람별 유효 결과를 확인할 수 있어야 한다. 반복/뒤로가기/입력 변경은 궤적 epoch를 끊고 이전 반복의 중복 판정·늦은 칭찬을 정리한다. 2인 중 한 명이 잠시 보이지 않으면 그 사람만 인식 대기하며 다른 사람의 기록으로 대신 채우지 않는다.

**팔을 따르는 시각.** 기존 Pose의 팔꿈치와 손목만 사용해 추가 모델 없이 구현할 수 있다. 거울 반전·가로세로 비율·사람별 좌표 변환을 동일하게 적용한다. 낮은 신뢰도, 팔꿈치 소실, 길이가 거의 0인 팔, 각도의 ±π 경계에서는 유한한 안정 방향을 사용한다. 잔상은 각 표본 당시의 방향을 보존한다. 포인터 체험은 이동 방향을 이용한 시각 대체임을 설명한다. 판정 모듈·손목 좌표는 시각 계산과 분리한다.

**세 베이스와 크기.** 정확도는 `100 × (1 − |교차 시각 − hitTime| / 0.25)`이며 성공 판정에서만 사용한다. 계속 베기의 음색/크기도 최초 교차의 정확도를 사용하고 이동 지속률과 혼동하지 않는다. 세 종류의 그룹 경계까지 포함해 정확도가 높아질 때 적용 이득이 줄어들지 않도록 한다. 미리듣기는 정해진 유효 정확도를 사용하고 실제 성공/칭찬을 만들지 않는다. 기존 최대 8버스트·중복 방지·동시 감쇠·중단 정리를 보존하고 PCM으로 유한값·최대 크기·무음을 검증한다. 신호 크기 측정은 사람이 느끼는 저음·음량·취향의 보증이 아니다.

**음성 범위.** 이번 구현은 새 안내 음성을 제작하지 않고 단계별 문장·자리 예시·실제 블록과 기존 성공 음성을 사용한다. 기존 36개 파일을 덮어쓰거나 런타임 음성 모델·외부 서비스를 추가하지 않는다. 새로운 전체 설명을 소리로 읽어 주는 기능은 완료로 주장하지 않는다.

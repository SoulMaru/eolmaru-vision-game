# 결정과 보류 기록

작성: 종합기획엔진, 2026-09-27 KST. 확정은 현재 MVP의 구현 범위이며 실제 카메라 검증 통과와 같은 뜻이 아니다.

최신 사용자 지시를 우선한다. **의자에 앉아 손만 사용하는 리듬 카테고리는 한 곡 종료**, **전신 스트레칭은 서기를 기본으로, 누워서 또는 커플 함께를 선택해 세트 종료**로 분리했다. 각 전신 세트는 3곡×75초=225초다. 이전 의자 스트레칭 가정은 폐기했다. 게임 같은 외형과 움직임 반응은 유지하고 보상·레벨·콤보 경쟁·누적 기록은 제외한다.

## MVP에서 제외하거나 보류한 기능

| 기능 | 상태 | 이유/재개 조건 |
|---|---|---|
| 상용 EZ2DJ 음악·스킨·채보 복제 | 제외 | 사용자 요청의 장르/입력 아이디어만 활용, 새 자산 사용 |
| 실제 3D 관절각 정밀 측정·의료적 교정 | 제외 | 단일 일반 카메라의 게임 포즈 점수를 해당 성능으로 주장할 수 없음 |
| 2인 얼굴/신원 인식 및 교차 이동 후 ID 고정 | 보류 | MVP는 화면 구역별 판정. 필요하면 동의와 실제 추적 검증을 포함해 별도 설계 |
| 깊은 허리/목 비틀기·점프·한발 균형 운동 | 제외 | 작은 범위의 전신 안내와 안정된 지지물 사용을 우선 |
| 의자에 앉는 스트레칭 프로필 | 제거 | 사용자가 의자 손동작은 리듬 전용이라고 명시. 스트레칭은 서기·누워서·커플로 분리 |
| 커플 상호 강제 스트레칭·파트너 체중 지지 | 제외 | 각자 몸을 조절하는 나란히 동작으로 구성. 파트너 힘·균형을 카메라로 검증할 수 없음 |
| 게임 중 ACE-Step 실시간 작곡 | 제외 | 음악은 사전 생성. 플레이 중 CPU/GPU 자원과 네트워크 요구를 늘리지 않음 |
| 다른 음악의 자동 박자/채보 생성 | 보류 | 이번 곡은 정확한 BPM 메타데이터 사용. 별도 곡 테스트가 필요 |
| 온라인 순위·계정·영상 업로드 | 제외 | 로컬 무료 실행과 카메라 영상의 로컬 처리에 집중 |
| 보상·레벨·경쟁 콤보·누적 점수/기록 저장 | 제외 | 최신 사용자 지시의 단순한 한 곡 흐름을 따름 |
| 손 리듬의 자동 다음 곡·무한 반복·장기 진행 구조 | 제외 | 손 리듬은 한 곡 종료. 전신 세트 안의 예정된2회 곡 전환은 포함 |
| Unity 전환·Krita 추가 제작 | 현재 미채택 | 사용 허용과 설치 확인은 별개. 품질/성능 개선의 근거가 생길 때만 재검토 |
| 복잡한 3D 연출·고강도 운동 | 현재 범위 밖 | 단순한 화면·가벼운 전신 안내를 우선하며 사용자 요청 없이 확장하지 않음 |

이 기능들은 막연히 불가능해서 지운 것이 아니라 현재 입력 장치·검증 범위·사용자 목표에 맞추어 제외하거나 보류한 것이다. 구현되지 않은 기능을 메뉴에 동작하는 것처럼 표시하지 않는다.

## 사용자가 고르면 좋은 다음 항목

현재 MVP 구현을 중단시킬 결정은 없다. 다음 목록은 필요한 경우의 취향 조정이며, 보상이나 복잡한 게임 구조를 고르라는 요청이 아니다.

1. **음악 취향:** 현재 밝고 가벼운 전자음 유지 / 댄스 비트 강화 / 잔잔한 스트레칭 음악 추가.
2. **캐릭터 방향:** 현재 창작 캐릭터 유지 / 사람형 코치 / 다른 동물형 캐릭터.
3. **실제 공간:** 서기 지지물 위치 / 매트와 카메라 구도 / 두 사람이 서로 닿지 않을 간격 보정. 세 자세 구성 자체는 이미 결정됨.
4. **코치 목소리:** 현재 한국어 해미 유지 / 안내 횟수 줄이기 / 음성 없이 화면 안내만 사용.
5. **실사용 보정:** 실제 카메라 거리·조명·두 사람이 설 수 있는 폭에 맞춰 기본 해상도와 입력 지연을 조정.

이 선택들은 현재 구현을 막지 않는다. 선택지 중 의료적 효과 측정이나 사용자 영상 외부 전송은 포함하지 않는다. 서기·바닥·커플 데이터 독립 시험과 실제 사람의 동작 검증을 구분한다.

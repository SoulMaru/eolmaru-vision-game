# 얼마루비전게임 단계별 계획

기준일: 2026-09-27 KST. 최신 범위는 두 카테고리다. **손 리듬은 곡 선택 → 한 곡 동안 손짓 → 종료**, **전신 스트레칭은 음악 3곡을 절반씩 들으며 225초 세트 → 종료**다. 스트레칭은 세트가 끝날 때 목·어깨·가슴·옆구리·다리·종아리·발목의 안내가 모두 끝나도록 구성한다. 보상·레벨·콤보 경쟁·기록 누적 같은 복잡한 게임 구조는 넣지 않는다. 무료·로컬 실행, 한 카메라로 최대 2인, 상단 캐릭터/목표와 하단 카메라, 무탈락 조건은 유지한다. 체크는 구현 또는 검증 증거가 존재할 때만 완료로 바꾼다.

현재 확인 단계: 이전 포즈·판정 코어의 독립 자동 시험 16개가 통과했다. 생성엔진은 합성 카메라 입력으로 로컬 GPU 모델 초기화와 외부 런타임 요청 0건을 확인했다고 보고했다. 이는 사람을 촬영한 실기 시험이 아니다. 최신 손 리듬/전신 225초 분리 흐름은 다시 통합 검증해야 하며, 게시와 실제 플레이 검증은 대기로 둔다.

## 확인한 환경과 추정

생성엔진이 현재 PC에서 확인해 공유한 환경은 Windows 11, Intel i5-12400F(6코어/12스레드), GTX 1660 Ti, 메모리 32 GB다. 독립 검토엔진은 USB 2.0 Camera 장치가 연결되어 상태 OK인 것을 확인했다. 음악 생성에는 로컬 Python 3.12, NumPy 2.5.2, FFmpeg를 실제 사용했다.

이 사양에서 MediaPipe lite와 낮은 입력 해상도가 적합할 것이라는 판단은 설계 가설이다. 연결 장치 존재만으로 영상 권한, 조명, 2인 인식 정확도 또는 실제 FPS를 확인한 것은 아니다. 실제 카메라 검증은 마지막 단계의 별도 항목으로 유지한다.

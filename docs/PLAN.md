# 얼마루비전게임 단계별 계획

기준일: 2026-09-27 KST. 최신 범위는 두 카테고리다. **손 리듬은 의자에 앉아 손으로만 한 곡 진행 → 종료**, **전신 스트레칭은 서서 진행을 기본으로, 누워서 또는 커플 함께를 선택해 225초 세트 → 종료**다. 스트레칭은 음악 3곡을 절반씩 사용하며, 세트가 끝날 때 목·어깨·가슴·몸통·다리·종아리·발목의 안내가 모두 끝난다. 의자 스트레칭 프로필은 두지 않는다. 보상·레벨·콤보 경쟁·기록 누적은 제외한다. 무료·로컬 실행, 한 카메라로 최대 2인, 상단 캐릭터/목표와 하단 카메라, 무탈락 조건은 유지한다. 체크는 구현 또는 검증 증거가 존재할 때만 완료로 바꾼다.

현재 확인 단계: 최신 서기·누워서·커플/손 리듬 구현은 독립 시험27개, 공통 브라우저14개 및 프로필 브라우저8개를 통과했다. 각13단계·225초·음성참조·바닥 무채점 조건과 선택기/종료/커플잠금을 확인했다. 최신 UI 통합·추가 게시 여부는 TEST_RESULTS.md와 HANDOFF.md를 따른다. 합성 카메라의 GPU 모델 초기화와 외부 런타임 요청 0건 확인은 사람을 촬영한 실기 시험이 아니다.

## 확인한 환경과 추정

생성엔진이 현재 PC에서 확인해 공유한 환경은 Windows 11, Intel i5-12400F(6코어/12스레드), GTX 1660 Ti, 메모리 32 GB다. 독립 검토엔진은 USB 2.0 Camera 장치가 연결되어 상태 OK인 것을 확인했다. 음악 생성에는 로컬 Python 3.12, NumPy 2.5.2, FFmpeg를 실제 사용했다.

이 사양에서 MediaPipe lite와 낮은 입력 해상도가 적합할 것이라는 판단은 설계 가설이다. 연결 장치 존재만으로 영상 권한, 조명, 2인 인식 정확도 또는 실제 FPS를 확인한 것은 아니다. 실제 카메라 검증은 마지막 단계의 별도 항목으로 유지한다.

진행을 막는 사용자 결정은 현재 없다. 사용자는 스트레칭의 기본 서기, 별도 누워서·커플 구성을 선택했고 의자 손 리듬과의 분리를 명시했다. 손 리듬은 한 곡 종료, 각 전신 프로필은 3곡×75초=225초다. 커플 프로필은 2인, 그 외는 1~2인·무탈락이다. Unity Hub와 Krita는 사용자가 이용 가능하다고 알려 주고 효과가 확실할 때만 사용하도록 허용했다. 실제 설치·성능 우위는 확인하지 않았으므로 현재의 가벼운 2D 구성을 유지한다. 남는 선택은 캐릭터·음악·음성 취향과 실제 카메라 보정 정도다.

통합 근거는 TEST_RESULTS.md다. 최신27개 독립 회귀와14+8개 브라우저 검사는 코드/합성 흐름의 검증이며 실제 사람의 운동 결과로 사용하지 않는다. 데이터·음성·UI 통합은 확인했고 실제 사용 대기는 별도로 추적한다.

## 개발 중 발견하고 수정한 것

코어/연결R01~R07은 REVIEW.md에 재현과 수정내용을 기록했다. 브라우저 시험 자체도 실제 초점 버튼에서 키보드 이벤트를 발생하도록 고쳤으며, 실제 클릭 없이 프로그램으로 음성을 시작하는 시험은 브라우저자동재생제한에 걸리므로 실제클릭후검사하도록 변경했다. 테스트파일업로드는 실행도구의 상대경로를 쓰면0바이트경로가될수있어 절대경로로다시검증했다. 이를 앱의코덱호환성실패로분류하지않는다.

## 남은 실제 사용검사

1. 실제 사람이 카메라앞에서 1인손리듬한곡/전신세트 완주.
2. 실제2인완주, 한사람퇴장·가림·좌우중앙구역·불충분한조명.
3. 실제웹캠/스피커의 체감박자지연과 설정보정.
4. 한국어음성과세곡의 청취, 조용한환경에서음량조정.
5. 의자배치와전신카메라구도, 사용자별편안한동작범위.

하체·목의 운동수행이나 운동효과를 자동검증한다는 합격항목은 없다. 해당구간은 시간/그림/음성안내로 제공한다.

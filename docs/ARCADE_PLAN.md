# 0.7 아케이드 반응·내 음악·바탕화면 실행 기획

2026-09-27 KST, 시작 기준 `5d260af`. 기획엔진은 AGENTS, README/PLAN/REVIEW/HANDOFF의 기존 계약과 TEST_RESULTS, 실제 실행기·음악 선택·효과음·렌더 연결을 읽었다. **0.7 개발 수락과 기획 대조 완료**다. 춤 정지/설정 저장 UI와 최종 자산 감사도 확인했으며,사람 청취·카메라는 별도 대기다. 이전0.6 자동131개·브라우저149개를 이번 결과로 재사용하지 않는다. 이번 담당의 수정 범위는 이 문서뿐이다.

## 확정 범위와 보존

1. 성공 타격음을 총성처럼 짧고 선명한 게임 효과음으로 강화한다. 로컬 합성의 빠른 어택·낮은 충격·짧은 잔향으로 존재감을 높이고 타격음 음량 조절/음소거를 유지한다. 운영체제 음량은 자동 변경하지 않는다. 실제 총성 녹음이나 출처 불명의 외부 샘플을 새로 가져올 필요는 없다.
2. 실제 바탕화면에 **얼마루 비전.lnk**와 프로젝트 ICO를 연결했다. 고정된 저장소의 `tools/launch.ps1`을 실행해 최신 파일을 연다. 별도 옛 실행본 복사, 자동 Git pull, 자동 설치/업데이트 서비스는 범위가 아니다. 생성엔진은 실제 바로가기로 Chrome의0.7.0이 열린 것을 확인했다.
3. **내 PC 음악** 버튼을 제공한다.120~180초 음악은 전체 한 곡을 사용하고,180초 초과180.02초 이하는 코덱 메타 오차로180초에 맞춘다. **180.02초보다 긴 음악은 앞150초만 진행 후 종료**한다. 원본 파일을 수정하거나 서버로 업로드하지 않는다. 기존100MB 제한과 브라우저 지원 형식 검증을 유지한다.120초 미만 파일은 거절하고 이전 선택을 보존한다.
4. 무지개색 배경과 새로 창작한 애니메이션풍 캐릭터의 **두 춤 포즈 이미지**를 교대한다. 음악2박마다 전환하되 최대 초당2회로 제한한다. 배경 춤 정지/줄이기와 운영체제 reduced-motion을 존중하고, 일시정지 시 그림도 멈춘다. 실제 새 이미지 생성은 시각 담당이며 특정 작품의 캐릭터·로고·원본 장면을 복제하지 않는다.
5. 단순한 곡 선택→한 곡 종료,1~2인,일반/지속 베기,무탈락·점수 보상 없음,별도 전신225초(서기/바닥/커플),왼쪽 조작/실제 전체화면을 보존한다. 현재 **음악12곡/손 리듬 선택10곡과 한국어 음성36개**는 변경/재생성 대상이 아니다. 무료 로컬 실행과 런타임 외부 요청0을 유지한다.

## 내 음악의 길이와 편집 계약

- `src/local-music.mjs`의 `localTrackPlan`이 `sourceDuration`과 `duration`을 구별한다. 유한한120~180초는 원본 길이,180~180.02초는180초,180.02초 초과는150초다. 초기 엄격180초 구분은 Vorbis 메타 오차20ms를 허용하도록 조정했다. 짧은120초 미만과 비수치는 거절한다.
- 버튼 옆에 **'2분 이상 · 긴 노래는 앞2분30초'**와 사용 길이를 안내한다. 짧은 곡의 거부는 선택 후 뒤늦게만 알리지 않도록 사전 문구를 둔다. 긴 곡을 자동으로 짧게 사용하는 방식은 간단한 흐름을 유지하기 위한 결정이며 별도 trim 편집기나 구간 선택을 추가하지 않는다.
- 원본 blob URL은 그대로 사용하고 게임/HUD/진행률/채보·지속 타겟 마지막 여유/결과/종료 시계는 플레이 길이에 맞춘다.150초 경계에서 한 번만 끝내며 뒤의 오디오·예약 타격음·입력을 정리한다. 늦은 원본 `ended`가 새 세션을 끝내면 안 된다.
- **채보 편집기의 별도 미리듣기**도150초에서 멈추고,loop/seek/import/export 검증은 플레이 범위를 따른다. 긴 파일 자체가 편집 JSON에 들어가거나 배포 자산으로 복사되지 않는다. 원본 채보와 실행용 접근/간격 파생 정책은 유지한다.
- 파일 취소·형식 오류·짧은 파일·크기 초과·느린 메타데이터·동시에 곡/모드 변경 시 이전 유효한 곡/채보를 보존한다. 성공한 교체 뒤에만 이전 blob URL을 해제하고, 새 선택 실패 시 새 URL만 정리한다.
- 내 음악 버튼은 기본 전신 화면에서도 보인다. idle에서 누르면 **손 리듬으로 전환해 파일 선택기**를 열고, 취소하면 손 리듬의 기존 유효 곡을 유지한다. 취소 때 전신으로 자동 복귀하지 않는 것이 실제 정책이다. 재생/준비/곡·채보 로딩 중에는 실행하지 않는다. 전신 고정3곡을 사용자 파일로 바꾸지 않는다.

## 소리와 두 포즈 배경

타격음은 짧은 블래스터로 구현했고 신규 기본 음량은75%,기존 저장 음량/음소거는 유지한다. 설정에 '타격음 들어보기'를 추가했고 미리듣기도 기존 중단 정리를 따른다. 독립 검토엔진의 실제 OfflineAudioContext20믹스+50ms stop 총21조건에서 최대peak0.7472112,최대RMS0.0540319,80ms 이후 무음을 확인했다. 같은 입력 조건의 단일 타격 RMS는 이전보다 약2.4~2.5배다. 이는 신호 크기 비교이며 사람이 느끼는 음량/취향의 배수를 뜻하지 않는다. 음악+칭찬까지 섞은 실제 청취는 별도다.

배경 교대 시계는 음악 시각이며 주기는 `max(0.5초,120/BPM)`이다.2박 교대와최대2회/초 상한을 함께 만족하고 무지개 밝기를 박자마다 번쩍이지 않는다. B포즈에서 일시정지하면 A로 튀던 초기 오류는 독립 검토가 재현했고,수정 후 playing→paused→resuming의 같은 음악 시각에서 같은 포즈를 유지한다. idle/reduced-motion과 새 `dance-motion=off` 설정은 고정 A포즈다. 생성엔진이 실제 게임stage의 drawImage를 관찰한8개와 off 저장 후 실제reload1개를 통과했고 시험 설정은on으로 복원했다.

창작 두 캐릭터를 각각 다른 춤 포즈로 그린 `dance-a.png`/`dance-b.png`는 각1536×1024의 투명 PNG,합계3,813,361bytes다. 시각 담당이 실제 alpha·A/B 차이·인물/포즈를 확인했고 경위와 해시는 DANCE_ART에 기록했다. 두 이미지는 로컬에서 각1회 로딩·캐시 재사용하며,low는 빛살/바닥 장식을 줄이고 이미지 실패/시간초과에는 기존 배경으로 플레이를 유지한다. 두 이미지를 교체하는 연출이며 관절 애니메이션이나 카메라 사람의 춤을 따라 하는 기능은 아니다.
